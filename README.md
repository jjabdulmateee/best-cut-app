# Best Cut - Uber-Style Barber Booking App

A beautiful, modern, Uber-like barber booking platform built with Flutter for iOS and Android.

## 🎯 Features (Phase 1)

- ✅ Splash screen with app branding
- ✅ Role selection screen (Customer / Barber)
- ✅ Customer home screen with map view
- ✅ Uber-style draggable bottom sheet
- ✅ Barber listing with cards
- ✅ Barber profile screen with slot selection
- ✅ Clean, minimal Uber-inspired UI

## 🚀 Getting Started

### Prerequisites

- Flutter SDK (3.5.0 or later)
- Dart SDK
- Android Studio / Xcode

### Installation

1. Navigate to the project directory:
   ```bash
   cd "D:\coding\BEST CUT"
   ```

2. Get dependencies:
   ```bash
   flutter pub get
   ```

3. Run the app:
   ```bash
   flutter run
   ```

## 📱 Screens

1. **Splash Screen** - App logo with animation
2. **Role Selection** - Choose Customer or Barber
3. **Customer Home** - Map view with nearby barbers
4. **Barber Profile** - Detailed view with booking slots

## 🎨 Design System

- **Primary Color**: #1A1A1A (Dark Black)
- **Success Color**: #00AA5B (Green)
- **Accent Color**: #276EF1 (Blue)
- **Background**: White (#FFFFFF)
- **Cards**: White with soft shadows
- **Typography**: Clean, modern sans-serif
